# ClojureStar

Discover, compare and try out dialects from the Clojure family of languages.

ClojureStar brings the wider Clojure family together through a curated dialect
catalog, instant REPL launchers, browser-based tools and portable libraries.

[Dialect catalog](https://clojure.cc/dialects/) ·
[Try a REPL](https://clojure.cc/try/) ·
[Browser REPL](https://clojure.cc/repl/) ·
[Blog](https://clojure.cc/blog/)

## Projects

- [clojure.cc](https://github.com/clojurestar/clojure-cc) catalogs Clojure
  dialects and provides instant and browser-based REPLs.
- [Grenadine](https://github.com/clojurestar/grenadine) provides portable
  dependency resolution for Clojure dialects without requiring the JVM.
